アプリの説明プライバシー利用案内・条件

プライバシーポリシー

このページは、個人用ツール「Reishoneko YouTube Publisher」におけるデータの取り扱いを説明します。

取得する情報と利用目的

Googleの認可により、接続したチャンネルのID・名称、依頼された操作に必要な動画情報や公開統計などをYouTube Data APIから取得します。公開コメントの取得を依頼された場合は、そのコメント情報も扱います。取得した情報は、所有者が依頼する動画制作・投稿管理・情報整理と、投稿先の照合に使用します。

認証にはOAuthのクライアント情報とトークンを使用します。Googleのパスワードの入力と管理はGoogleの認証画面で行います。

保管場所とデータの共有

認証情報は所有者のPCの保護された領域、または選択したクラウド作業環境の個人用保管庫で管理します。作業に必要なデータは、所有者が選択したPC・クラウド作業環境・非公開の保存先で扱います。制作コードや管理記録には非公開GitHubを、制作素材には本人が設定した非公開Google Driveを利用します。認証情報をソース管理や一般公開の説明ページに含めません。

GoogleとのAPI通信に加え、クラウドでの依頼の実行にはOpenAIのサービスを利用します。各サービスでの取り扱いは、そのサービスの設定とポリシーに従います。Google APIから受け取った情報の利用および転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

接続解除・削除

Googleアカウントの接続管理から、本ツールのアクセスを取り消せます。接続解除後の新たなAPIアクセスは停止します。取得済みのファイルや作業記録は自動では削除されないため、所有者が利用したPC・クラウド・保存先で確認し、必要に応じて削除してください。

この説明サイト

このサイトはGitHub Pagesで配信します。独自のアクセス解析、外部フォント、画像やスクリプトは使用していません。配信に伴う接続情報の取り扱いについては、GitHubのプライバシーに関する説明をご確認ください。

問い合わせ

Googleの認可画面に表示されるユーザーサポートメールへご連絡ください。
