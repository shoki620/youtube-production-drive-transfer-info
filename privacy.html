プライバシーポリシー

YouTube Production Drive Transfer における情報の取り扱いについて説明します。

扱う情報と目的

利用者がこのツールで保存・取得するファイルの内容と、ファイル名、ファイル・フォルダの ID、サイズ、ハッシュなどの情報を扱います。これらはファイルの転送、復元、内容の照合、作業状態の記録と再開のために使います。

Google Drive のアクセスには drive.file の認可を使用し、このツールが作成したファイルとフォルダを対象にします。

保存先と処理先

  • 転送するファイルは、利用者の Google Drive と、選択した PC またはクラウドの作業領域で保存・処理します。処理中の一時ファイルも作業領域に置きます。
  • プログラム、設定、ファイル名やハッシュ、作業状態などの管理情報は、選択した非公開 GitHub リポジトリで管理します。
  • OAuth の認証情報とトークンは、PC の保護された領域、またはクラウドの個人用秘密情報保管で扱います。認証情報は、保管用アーカイブや作業報告へ含める対象から除外します。

利用者が選択した Google Drive、GitHub、PC、クラウド実行環境が、保存と処理の経路になります。本ツールには広告配信やデータ販売の機能はありません。

保存済みファイルの管理

保存したファイルや作業記録は、それぞれの保存先に残ります。利用者が必要に応じて各保存先で管理・削除します。接続を解除しても、作成済みのファイルを自動的に削除する仕組みではありません。

Google Drive へのアクセスの取り消し

Google アカウントの接続でこのアプリを選び、アクセスを取り消せます。これはその後の Drive アクセスを止める操作で、すでに PC やクラウドへ取得したコピーを回収・削除する操作ではありません。保存・取得済みのファイルは各保存先で別に管理してください。

この説明サイトの配信

この説明サイトは GitHub Pages で配信します。GitHub はセキュリティの目的で、閲覧者の IP アドレスを記録・保存します。詳しくは GitHub のプライバシーについての説明をご確認ください。この説明サイトに独自のアクセス解析や広告は設置していません。
